# Docker class catalog update

Published two replacement Docker courses to the Training Academy:

- **Docker: Beginner** — 10 learning modules, module quizzes, an opening pretest, and a final exam.
- **Docker: Intermediate** — 10 learning modules, module quizzes, an opening pretest, and a final exam.

Assessments use an 80% passing score and provide explanations after grading. Both courses are visible in the Docker catalog filter. Instructor answer keys and course package files remain private and are not included in this public release note.
