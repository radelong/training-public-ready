# Generic configuration and credentials

This source package contains no intended owner-specific network, account or hosting configuration. Example domains use reserved example names; lab addresses describe fictional isolated networks. Loopback, wildcard addresses, standard protocol ranges and public DNS resolvers are technical examples. Vendor registries, documentation, dependency funding links and required copyright notices identify third-party software. They do not identify the original application owner.

All literal passwords in tests, build-check containers and tutorials are synthetic, generic examples. TestOnly/test-only values and REPLACE_WITH_YOUR_SECRET are never production credentials. Short invalid strings exercise rejected-password paths. Repeated hexadecimal keys and tutorial tokens are synthetic fixtures. Runtime installers generate fresh credentials; production authentication requires operator-supplied secrets outside Git. Do not deploy test fixtures as production credentials.

The package omits original user records, submitted documents, original photographs, learner records, original Git history and private deployment configuration. Git author metadata is generic. GitHub account ownership remains visible on GitHub and is outside the source package.
