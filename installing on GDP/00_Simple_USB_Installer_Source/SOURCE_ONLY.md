# GDP USB installer source

This directory contains the installer launchers and setup scripts used by the GDP USB package. It is a source review copy, not an installable package. The runnable package includes separately verified Ubuntu media, lab templates, class slides, assessments, games and protected answer keys. Those assets are excluded from the public repository.

The complete USB package and its 59-file checksum manifest are distributed through the controlled GDP handoff. Use its `README.md` and `VERIFY.ps1` before installation. Do not run `INSTALL.sh` from this source-only directory.


The standalone installation troubleshooting guide is included as Markdown and PDF. It documents safe install-step diagnostics and stop points without including offline media or deployment credentials.


The installation guide now includes Ubuntu learner-PC DNS and certificate trust steps. The public copy contains only generic documentation and tooling; offline media, credentials, private answer keys, learner records and lab disks remain excluded.

The Ubuntu learner-client troubleshooting PDF is named INSTALL-TROUBLESHOOTING-UBUNTU.pdf.
