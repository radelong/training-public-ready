# Docker Troubleshooting Lab — 28 October 2026

A separately installed Training Academy lab provides 18 Docker and Compose troubleshooting exercises in a private Ubuntu VM. The approved profile uses two vCPUs, 8 GiB memory and a 32 GiB virtual disk. Required container images are supplied locally, and Academy provisions a separate VM for each learner.

The package installer generates a target-specific receipt after its readiness check. Administrators import the receipt and validate the terminal, exercise behavior and network isolation on their own installation before activating the lab. The VM package and protected exercise solutions are distributed separately and are not part of this public source repository.

This note is a release record, not a fresh-install image. The staging exercise review covered all 18 drills. Two concurrent learner sessions and full production browser exercise completion remain to be verified.
