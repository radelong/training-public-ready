# Prompt Engineering course update

The Training Academy now publishes expanded version 2 of Prompt Engineering: Foundations and Prompt Engineering: Advanced Practice. Each course has five modules with eight instructional slides per module. The courses retain self-graded module quizzes, self-graded final exams, an 80% pass score, and randomized retake order.

The expanded lessons use a shared offline slide theme. The authenticated Academy and instructor-only offline import package contain the course material. This public release note includes no slides, questions, answer keys, grading explanations, user data, credentials, or deployment secrets.
