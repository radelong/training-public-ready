# Kubernetes and K3s command class

The Academy includes a beginner class on Kubernetes and K3s command-line fundamentals. Five modules cover safe access, resource inspection, workloads, services and configuration, and troubleshooting. Each module has 27 slides and a knowledge check. The optional opening pretest can grant credit for individual modules, and a separate final exam uses an 80% passing threshold.

The private GDP candidate contains this class alongside the existing courses, labs and games. The fresh installer and its import checks were updated to expect eleven classes. A complete installation on an empty Proxmox node remains unverified. Course PDFs, answer keys and the complete installation media are maintained separately and are not included in this public release note.
