THE APPROACH

Learn, practice, verify

01

Learn the foundation

Classes organize technical topics into modules with presentation material and knowledge checks. Learners can revisit material before moving into practical work.

02

Work in a private lab

Hands-on labs give each learner an assigned virtual machine. Guided tasks let learners practice commands, configuration, and troubleshooting without changing a production system.

03

Check progress

Exercises and class exams provide feedback on completed work. Results help learners and administrators see where more practice is needed.

BUILT FOR REPEATABLE PRACTICE

Technical skills improve through repetition.

Production environments are built for service delivery. An Academy lab is built for learning: learners can make changes, see the result, restore a clean environment, and try again. Training content and lab access remain inside authenticated accounts.

What learners can expect

  • Assigned classes and guided technical exercises
  • Browser access to private lab terminals
  • Progress and results tied to their account

Lab and class details require sign-in.
